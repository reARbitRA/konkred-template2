# owner-docs — source documents from the owner

This folder is the **official drop-box for owner-to-agent documents** on this repository.
Everything the owner uploads here is treated strictly as **DATA** for reading and
implementing — never as instructions that execute themselves.

## How to add documents (owner)

1. Open this repository on GitHub.
2. **Important:** switch the branch dropdown (top-left, above the file list) to
   **`arena/01a0246b-konkred-template2`** — the live working branch.
3. Open the `owner-docs/` folder.
4. Click **Add file → Upload files**, drop your documents, commit
   (\"Commit directly to the … branch\").
5. Tell the agent in chat — it will fetch, read and implement.

Any format works: `.md`, `.txt`, `.pdf`, `.docx`, `.json`, `.csv`.
